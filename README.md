## Core Competencies & Knowledge Domains

* **Incident Scoping & Triage:** Identifying problem scope (single user vs. multi-user/network-wide impact), establishing symptoms, and formulating step-by-step diagnostic workflows.
* **Customer Interaction Framework:** Implementing the "Know, Relate, and Understand" communication model; managing difficult or talkative end-users via active listening, polite refocusing, and direct questioning without technical jargon.
* **Remote Support Administration:** Pre-session communication, software compatibility verification (e.g., VNC, RDP), secure end-user authorization, and hands-on remote troubleshooting.
* **AI-Assisted Ticketing Systems:** Utilizing AI agents for automated routine task handling, data-driven ticket classification, and predictive performance analysis while retaining human verification of technical solutions.
* **Documentation & Knowledge Management:** Formulating reproducible incident records, updating structured knowledge bases, and compiling Standard Operating Procedures (SOPs).
